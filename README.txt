PIP HELPER V3 — REAL AI CHAT

This build adds a real AI chat connection through a server.

IMPORTANT: Never put your OpenAI API key in public/index.html or browser JavaScript.

On a computer:
1. Install Node.js.
2. Run: npm install
3. Copy .env.example to .env
4. Put your API key in .env
5. Run: npm start
6. Open http://localhost:3000
